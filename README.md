# 🚗 Car Rental & Ticket Booking System

## 📱 Overview
**Car Rental & Ticket Booking System (2022)** is a dual mobile application designed for **vehicle rental services** and **online ticket booking for transportation companies**.  

The main purpose of the car rental app is to allow users to **reserve a specific car with selected specifications**. The app provides a seamless experience from selecting available cars to entering passenger information and completing payments.

---

## 🚀 Key Features

### 🏎️ Car Rental
- 📅 **Reservation Date Selection** — Users choose the date of their trip.
- 🚗 **Available Cars Display** — All cars available on the selected date are shown.
- ⚙️ **Advanced Filters** — Filter cars by model, number of seats, fuel type, and other specifications.
- ✅ **Reservation Confirmation** — After selecting a car, users confirm their choice.
- 🧑‍🤝‍🧑 **Passenger Information** — Enter names and details for all passengers included in the booking.
- 💳 **Payment Integration** — Complete the reservation via a bank transfer number.
- 📝 **Booking History** — Users can view all their past and current bookings.
- 🔄 **Seamless Navigation** — Return to the main interface after payment to continue browsing or managing bookings.

### 🎫 Ticket Booking
- Book tickets for transportation companies using a simple and intuitive interface.
- View available schedules and select preferred trips.
- Enter passenger details for ticketing.
- Complete payment via bank transfer.

## ⚙️ How It Works
1. User opens the app and selects the **desired trip date**.
2. The app fetches **available cars** for that day via the API.
3. Users can **filter cars** by model, seats, fuel type, and other criteria.
4. After selecting a car, the app navigates to the **passenger details screen** where names and other data are entered.
5. User proceeds to **payment**, completing the transaction via bank transfer.
6. Once the payment is completed, the app returns to the main interface.
7. Users can **view all their bookings**, manage reservations, and check past trips.

---

## 🧠 Purpose
This app is designed to provide a **streamlined car rental and ticket booking experience**. Users can easily select the right vehicle, manage passenger information, and complete reservations without the need for physical paperwork or manual booking.
